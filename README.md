# 匠心皮具 · 手工定制下单系统

一个基于 Svelte + Vite 构建的手作皮具刻字定制下单系统，包含顾客端定制页面和店员端管理工作台。

---

## 原始需求

> 请制作手作皮具刻字下单页面，Svelte 页面让顾客选择皮革颜色、纹理、五金、版型、刻字内容、刻字位置、礼盒和取货方式。用户在手机上能实时预览钥匙扣、卡包、短夹或护照夹的外观，刻字字符数、字体、压印深浅和边距要跟随输入变化；店员平板端查看待制作订单、材料余量、预计完工日和特殊备注。这个页面要让顾客像在工坊里确认定制单，材质、刻字和交期都可视化，不能让最终成品与下单预期差太远。

---

## 项目简介

### 核心功能

**顾客端（手机端友好）**
- 🎨 **版型选择**：钥匙扣 / 卡包 / 短夹 / 护照夹 四种皮具
- 🟫 **皮革定制**：6种皮革颜色 + 5种纹理（平纹/荔枝纹/卵石纹/麂皮绒/鳄鱼纹）
- 🔩 **五金选择**：黄铜金 / 亮银 / 玫瑰金 / 枪黑
- ✍️ **刻字配置**：
  - 实时字符计数与超额计费（前3字免费，超出¥8/字）
  - 5种字体（衬线/无衬线/手写/等宽/印章）
  - 3档压印深浅
  - 多种刻字位置（正面/背面/内侧/书脊等，依版型不同）
  - 边距滑块实时调节（3mm - 25mm）
- 🎁 **礼盒包装**：简易 / 标准礼盒 / 豪华磁吸礼盒
- 🚚 **取货方式**：门店自提 / 顺丰快递 / 同城闪送
- 👁️ **实时 SVG 预览**：版型、皮革色、纹理、五金、缝线、刻字、边距、礼盒全部同步可视化
  - 刻字越界时自动显示红色双虚线边框警示
  - 缝线颜色、扣具样式、礼盒效果即时呈现
- 📅 **预计完工日期**：基于版型、工艺、皮革类型和材料替代自动计算（含额外天数提示）
- 💳 **动态价格计算**：所有选件即时影响总价
- ✅ **订单确认弹窗**：
  - 订单确认前自动检查刻字越界和字符验证
  - 自动检查材料可用性，如有售罄则阻止提交并提示
  - 含警告信息显示和确认按钮状态控制
  - 🎉 **下单成功反馈**

**店员端（平板端友好）**
- 📋 **订单管理**：
  - 状态筛选（待开始/制作中/已完成/已交付）
  - 订单卡片含微型预览图、材质、刻字、客户信息、特殊备注
  - 加急订单红色标识
  - 进度条展示制作进度
  - 点击查看完整详情
  - 一键切换订单状态（开始制作 / 标记完成 / 已交付）
  - 制作进度滑块人工调整
- 📦 **材料库存管理**：
  - 皮革 / 五金 / 缝线 三大品类
  - 实时库存进度条
  - 低库存红色预警
  - 未来7天物料消耗预测
- ⚙️ **生产进度总览**：
  - 4个数据统计卡片（待开始/制作中/已完成/营业额）
  - 时间轴形式的近期完工安排
  - 含加急、备注、进度可视化

### 技术亮点
- 纯前端响应式单页应用，无需后端即可体验完整流程
- 真实 SVG 绘制皮具预览，刻字深浅用透明度+阴影模拟
- Svelte 响应式驱动，任何配置变更即时反映
- 内置模拟订单与库存数据，开箱即用

## 启动方式

### 前置要求

- **Node.js** ≥ 18.x（推荐 20 LTS）
- **npm** 或 **pnpm** / **yarn** 任选其一
- **Docker** ≥ 24.x（仅 Docker 启动需要）
- **Docker Compose** ≥ v2（仅 Docker 启动需要）

### 启动步骤

#### 方式一：本地开发启动（推荐用于开发调试）

##### 1. 安装依赖

```bash
npm install
```

（使用 pnpm 则：`pnpm install`）

##### 2. 启动开发服务

```bash
npm run dev
```

访问地址：**http://localhost:5173**

> - 顾客下单页：默认访问即为顾客端
> - 店员工作台：点击页面右下角 **🛠 切换到 店员工作台** 按钮，或访问 `http://localhost:5173/?staff=1`

##### （可选）构建生产版本

```bash
npm run build
```

构建产物在 `dist/` 目录。启动生产预览：

```bash
npm run preview
```

访问地址：**http://localhost:4173**

---

#### 方式二：Docker 一键启动（推荐用于部署验证）

> 本项目根目录已包含完整的 Docker 配置：`Dockerfile`、`docker-compose.yml`、`.dockerignore`。

##### 1. 一键构建并启动

```bash
docker compose up --build
```

（后台运行可加 `-d`）

```bash
docker compose up --build -d
```

##### 2. 访问服务

等待构建完成并启动后，访问：

- **生产环境地址**：**http://localhost:4173**

##### 3. 查看日志（后台运行时）

```bash
docker compose logs -f
```

##### 4. 停止并清理服务

```bash
docker compose down
```

> 如需验证 compose 配置语法：
> ```bash
> docker compose config
> ```

## 注意事项

1. **数据持久化**：当前为纯前端演示，订单与库存存储在浏览器内存中，刷新后重置。如需生产使用，请接入后端 API。
2. **皮革纹理可视化**：由于 SVG fill 仅支持纯色，纹理效果通过在预览卡片上叠加 CSS `background-image` 模拟，已足以让顾客感知平纹与鳄鱼纹的差异。
3. **手工误差声明**：在订单确认页中已内置 "手工制品可能存在±1mm误差" 提示，降低客诉风险。
4. **店员端操作**：开始制作 → 调整进度滑块 → 标记完成 → 已交付，是标准工作流。
5. **移动端体验**：顾客端采用 4 步向导式 UI，底部固定操作栏，适配手机单手操作。
6. **跨端切换按钮**：右下角悬浮按钮可一键切换顾客/店员视图，方便演示验收。
